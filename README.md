# Glow Beauty — Современный интернет-магазин косметики

Премиальный e-commerce проект для демонстрации каталога косметики, корзины, чекаута и тестовых интеграций платежных систем **Stripe** и **Payme (Узбекистан)**.

---

## 🌸 Особенности и дизайн

- **Эстетика**: современный минималистичный дизайн в нежных розово-бежевых и нюдовых тонах (`#FAF7F2`, `#FDF8F9`, `#CA6B8B`), типографика с акцентным шрифтом Cormorant Garamond и чистым гротеском Plus Jakarta Sans.
- **Адаптивность**: полноценный responsive-дизайн для смартфонов, планшетов и широкоформатных экранов.
- **Интерактивность**: плавные hover-эффекты, увеличение фото при наведении, плашка бесплатной доставки, выдвижная боковая корзина (Drawer) и детальная страница корзины.
- **Архитектура**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide Icons, серверные API-роуты и файловая база данных для сохранения заказов.

## 📑 Страницы проекта

1. **Главная страница (`/`)**:
   - Hero-баннер с новинками сезона и слоганом «Искусство естественного сияния».
   - Категории косметики (Уход за кожей, Макияж, Парфюмерия, Тело и СПА, Подарочные сеты).
   - Бестселлеры и новинки с быстрым добавлением в корзину.
   - Философия бренда (Чистые формулы, Cruelty-Free, доказанный эффект).
   - Промо-баннер с промокодом `GLOW10`.

2. **Каталог товаров (`/catalog`)**:
   - Фильтрация по категориям в один клик.
   - Живой поиск по названию, описанию и категории.
   - Сортировка (по популярности, цене возрастания/убывания, рейтингу).
   - Переключатель «Только в наличии».

3. **Страница отдельного товара (`/product/[id]`)**:
   - Галерея фотографий косметики с зумом и превью.
   - Выбор количества, бейджи бестселлера/новинки, объем средства.
   - Табы: «Описание и преимущества», «Полный состав (INCI)», «Способ применения».
   - Кнопки «В корзину» и «Купить в 1 клик».
   - Блок рекомендаций «Похожие средства».

4. **Корзина (`/cart`) + Slide-over Drawer**:
   - Добавление, изменение количества (+/-) и удаление товаров.
   - Индикатор прогресса до бесплатной доставки (порог $75).
   - Промокоды: `GLOW10` (скидка 10%), `WELCOME15` (скидка 15%).
   - Расчет Subtotal, скидки, доставки и итоговой суммы (в USD и сумах UZS).
   - Переход к чекауту.

5. **Оформление заказа (`/checkout`)**:
   - Ввод имени, email, номера телефона и адреса доставки.
   - Выбор способа оплаты:
     - **Stripe (Банковская карта)**
     - **Payme (Локальный провайдер Узбекистана)**
   - Прозрачный состав заказа и перерасчет итоговой стоимости.

6. **Страница успешной оплаты (`/checkout/success`)**:
   - Номер заказа, состав покупок, способ оплаты и статус транзакции.
   - Ссылка на отслеживание заказа.

7. **Страница неуспешной оплаты (`/checkout/cancel`)**:
   - Детальное сообщение о причинах отмены.
   - Кнопки для повторной попытки оплаты или смены способа оплаты.

8. **История и детали заказа (`/order/[id]`)**:
   - Таймлайн-степпер статусов: *Ожидает оплаты → Оплачен → В сборке → Передан курьеру → Доставлен*.
   - Полный состав покупки, данные клиента и ID платежной транзакции.

9. **Панель администратора (`/admin`)**:
   - Общая выручка (USD и UZS), количество заказов, средний чек, статистика по Stripe/Payme.
   - Таблица заказов с поиском и фильтром по статусам.
   - Возможность смены статуса любого заказа в реальном времени.

## 💳 Интеграции оплаты

### 1. Stripe (Test Mode)
- **Безопасность**: `STRIPE_SECRET_KEY` используется **только на стороне бэкенда** (`src/lib/payments/stripe.ts` и `/api/checkout/stripe`). Секретный ключ никогда не попадает во frontend-код.
- **Поддержка**: если указаны реальные тестовые ключи Stripe (`sk_test_...`), создается официальная сессия Stripe Checkout. Если ключи не заданы, автоматически включается интерактивный **Stripe Test Mode Simulator** (`/checkout/stripe-simulator`), где можно проверить сценарии успешной оплаты и отказа без необходимости предварительной настройки аккаунта Stripe!
- **Тестовая карта**: `4242 4242 4242 4242`, CVC `123`, срок `12/28`.

### 2. Payme (Узбекистан)
- **Архитектура**:
  - Модуль платежного сервиса: `src/lib/payments/payme.ts`.
  - Эндпоинт создания сессии: `/api/payments/payme/create`.
  - Эндпоинт вебхука / callback: `/api/payments/payme/callback` (реализует протокол **JSON-RPC 2.0** Payme Merchant API).
  - Методы: `CheckPerformTransaction`, `CreateTransaction`, `PerformTransaction`, `CheckTransaction`, `CancelTransaction`.
  - Проверка авторизации `Basic Paycom:secret_key`.
  - **Правило**: статус заказа изменяется на `paid` **только после подтверждения успешной транзакции** методом `PerformTransaction`.
  - **Интерактивный симулятор Payme Sandbox** (`/checkout/payme-sandbox`): позволяет наглядно увидеть весь цикл обмена сообщениями, отправку SMS-кода подтверждения (`666666`) и реальный webhook в бэкенд с логами консоли.

## 🚀 Запуск проекта

1. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере:
   ```
   http://localhost:3000
   ```

4. Сборка для продакшена:
   ```bash
   npm run build
   npm start
   ```
